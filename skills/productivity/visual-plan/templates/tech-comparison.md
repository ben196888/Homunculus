# Template: tech-comparison

Use when choosing among technologies, libraries, or approaches.

| Section | Default visual |
| --- | --- |
| Options side by side | Architecture or feature comparison diagram / columns |
| Scored matrix | Scored matrix table (criteria × options) |
| Trade-off heat map | Heat map (option × concern intensity) |
| Recommendation | Short prose (≤3 lines) + decision callout |
| Verification / next checks | Short checklist |
| Out of scope | Short list |

Outputs: follow SKILL.md — always emit plan.md and visual-plan.md; also emit
visual-plan.html and a Canvas when the environment supports them (skip either when unavailable).
