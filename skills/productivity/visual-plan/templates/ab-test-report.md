# Template: ab-test-report

Use for experiment write-ups and go/no-go decisions from measured results.

| Section | Default visual |
| --- | --- |
| Hypothesis | Short prose (≤3 lines) |
| Setup flow | Workflow chart |
| Results | Charts with confidence ranges |
| Segments moved | Segment comparison chart or table |
| Decision | Decision table or clear go/no-go callout |
| Verification / follow-ups | Short checklist |
| Out of scope | Short list |

Outputs: follow SKILL.md — always emit plan.md and visual-plan.md; also emit
visual-plan.html and a Canvas when the environment supports them (skip either when unavailable).
